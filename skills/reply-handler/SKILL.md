# 기자 답장 응대 스킬 (reply-handler)

기자 회신은 **관계의 시작**이다. 빠르고 정확한 응대가 게재율을 좌우한다.
이 스킬은 회신을 자동 분류하고, 유형별 답장 초안을 사내 톤으로 생성한다.

## 응대 3원칙

1. **속도**: 인터뷰/자료 요청은 **당일**(늦어도 2시간 내) 회신. 기자는 마감이 있다.
2. **정확**: 물어본 것만, 팩트로. 과장·홍보 반복 금지.
3. **관계**: 이번에 안 써도 다음이 있다. 항상 정중하게, DB에 기자 성향 메모.

## 회신 자동 분류 (7유형)

들어온 메일을 아래로 라벨링한다. (Gmail MCP 사용 시 `mcp__Gmail__label_thread`로 실제 라벨 부착)

| 유형 | 신호 문구 | 우선순위 | 담당 액션 |
|---|---|---|---|
| ① 인터뷰 요청 | "인터뷰", "통화 가능", "일정" | 🔴 즉시 | 일정 3안 제시 + 대표 연결 → Pro `interview-prep` |
| ② 자료 요청 | "고화질 이미지", "추가 자료", "매출 자료" | 🔴 즉시 | 요청 자료만 정확히 첨부/링크 |
| ③ 확인 질문 | "○○가 맞나요", "수치 근거는" | 🟠 당일 | 팩트만 간결히, 근거 링크 |
| ④ 게재 통보 | "기사 나갔습니다", 링크 | 🟢 감사 | 감사 회신 + 관계 유지 + 성과 집계 |
| ⑤ 보류/거절 | "이번엔 어렵", "다음 기회" | 🟢 정중 | 감사 + 다음 소식 예고, 관계 유지 |
| ⑥ 수신거부 | "수신거부", "그만", "빼주세요" | ⚫ 즉시 | 억제 리스트 등록 + 사과 없는 정중한 확인 |
| ⑦ 부정/컴플레인 | 사실오류 지적, 항의 | 🔴 신중 | 사실 확인 후 정정, 방어적 태도 금지 |

## 유형별 답장 톤 & 템플릿

### ① 인터뷰 요청
빠르게, 선택지를 주고, 대표를 연결한다.
```
{{기자성}} 기자님, 관심 가져주셔서 감사합니다. 대표 인터뷰 가능합니다.
아래 중 편하신 시간 알려주시면 맞추겠습니다.
· {{일정1}} · {{일정2}} · {{일정3}}
대면/화상/전화 모두 가능하며, 필요하신 자료 미리 보내드리겠습니다.
```

### ② 자료 요청
군더더기 없이 요청한 것만.
```
{{기자성}} 기자님, 요청하신 자료 전달드립니다.
· {{요청자료1}}: {{링크}}
· {{요청자료2}}: {{링크}}
추가로 필요하신 것 있으면 언제든 말씀 주세요.
```

### ③ 확인 질문
팩트 + 근거. 홍보 문구 덧붙이지 않는다.
```
{{기자성}} 기자님, 문의 주신 내용 확인해 답변드립니다.
{{질문}} → {{정확한 답}}. (근거: {{링크/출처}})
```

### ④ 게재 통보
진심 어린 감사 + 다음 관계. (사내 성과 집계에 게재 1건 기록 — Pro `campaign-report`가 게재율·관계 스코어 +5 반영)
```
{{기자성}} 기자님, 좋은 기사로 다뤄주셔서 진심으로 감사합니다.
덕분에 {{반응/성과}} 있었습니다. 앞으로도 의미 있는 소식 있을 때 먼저 전해드리겠습니다.
```

### ⑥ 수신거부 (컴플라이언스 핵심)
변명·설득 없이 즉시 수용. 그리고 **반드시 억제 리스트에 등록**.
```
{{기자성}} 기자님, 알겠습니다. 명단에서 즉시 제외했습니다. 좋은 하루 보내세요.
```
→ 처리: 해당 이메일을 suppression list에 추가. `press-distribution` 재발송 대상에서 영구 제외.
→ Gmail MCP: `mcp__Gmail__label_thread`로 `언론홍보/수신거부` 라벨 부착.

### ⑦ 부정/컴플레인
절대 방어적/감정적으로 대응하지 않는다. 사실 확인 → 정정/사과.
```
{{기자성}} 기자님, 지적 감사합니다. 확인 결과 {{사실관계}}.
{{정정내용}}. 혼선 드려 죄송하며, 정확한 자료 다시 보내드리겠습니다.
```

## 답장 초안 생성 워크플로우

**Gmail MCP 연결 시:**
1. `mcp__Gmail__search_threads` — `label:언론홍보` 또는 캠페인 라벨(`언론홍보/캠페인/{캠페인명}`)로 미응답 회신 수집
2. `mcp__Gmail__get_thread`로 원문 파악 → 위 7유형으로 분류
3. 유형별 템플릿으로 `mcp__Gmail__create_draft`(`replyToMessageId` 지정) 초안 생성
4. 사용자 검토 후 발송 / 수신거부·게재는 상태 자동 반영
5. 인터뷰 요청(①)이 확정 흐름을 타면 Pro `interview-prep`(Solo+)으로 넘겨 일정·예상 질문·리허설까지 준비

**GPT/Gemini 웹 시:**
사용자가 붙여넣은 회신 원문을 분류 → 답장 초안 텍스트 제공 → 사용자가 직접 회신.

## 응대 스타일 원칙 (사내 목소리)

- 존댓말, 간결, 담백. 이모지·과한 감탄사 금지.
- "감사합니다"는 진심으로 1회. 남발 금지.
- 대표/회사를 과장하지 않는다. 기자는 홍보를 싫어한다.
- 모든 회신 끝에 다음 관계의 여지를 남긴다("다음에 또").

## 절대 하지 말 것
- 수신거부 요청에 설득·재발송 시도
- 사실오류 지적에 방어·감정 대응
- 인터뷰/자료 요청 24시간 초과 방치
- 요청하지 않은 홍보자료 끼워넣기
