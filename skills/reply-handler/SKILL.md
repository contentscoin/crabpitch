# 기자 답장 응대 (reply-handler) — 정본 참조 스텁

> ## ⚠️ 이 문서는 요약본이다. **정본은 `skills-public/skills/reply-handler/SKILL.md`.**
>
> 하위 분류 기준·3단 스캐폴드·유형별 응대 포인트는 정본에 있다. 정본과 어긋나면 **정본이 맞다.**
> **코드 정본**은 `convex/lib/replyClassifier.ts`(유형·신호어·초안)이며,
> 수신거부 억제 등록은 `convex/replies.ts`가 서버에서 강제한다.

## 7유형 (판정 순서)

| 유형 | 우선순위 | 액션 |
|---|---|---|
| ① 수신거부 | ⚫ 즉시 | **최우선 판정.** 억제 리스트 등록 + 설득 없는 확인, `언론홍보/수신거부` |
| ② 게재 통보 | 🟢 | 감사 + 인용 정확성 점검 1줄 + 성과 집계 |
| ③ 인터뷰 요청 | 🔴 즉시 | 일정 3안 + 대표 연결 (→ Pro `interview-prep`) |
| ④ 자료 요청 | 🔴 즉시 | **원래 메일에서 약속한 자료만** |
| ⑤ 부정/컴플레인 | 🔴 신중 | 방어 금지. **에스컬레이션 대상 — 사람이 확인 후 회신** |
| ⑥ 확인 질문 | 🟠 당일 | 아래 5개 하위 유형으로 다시 나눈다 |
| ⑦ 보류/거절 | 🟢 | 정중히 수용, **자동 재접근 금지** |

수신거부는 다른 신호와 함께 있어도 항상 최우선이며, 억제 등록은 분류 경로와 무관하게 서버가 강제한다.
어디에도 걸리지 않으면 확인 질문(당일 응대)으로 안전하게 분류한다.

## ⑥ 확인 질문 5하위 유형

| 하위 유형 | 답변 원칙 |
|---|---|
| 수치 검증 | 값 + 산출 방식(기간·모수·기준) + 출처. 셋 다 없으면 확인 후 회신 |
| 경쟁사 비교 | 타사를 평가하지 않는다. 자사 사실만 |
| 전략 의도 | 공개 가능한 배경만. 미공개 계획 누설 금지 |
| 향후 계획 | 확정된 것만 시점과 함께. 미확정은 "확정되면 알려드리겠습니다" |
| 부정적 맥락 | 회피·반박 금지. 사실관계만 짧게, 즉답을 서두르지 않는다 |

## 답장 초안 3단 스캐폴드 (확인 질문·컴플레인)

```
[공식 답변]                 확인된 사실 한 문장 + 근거(출처·기준·시점). 빈칸은 담당자가 채운다
[대체 표현 — 하나 고르세요]  하위 유형에 맞는 표현 2개
[이렇게는 말하지 않기]        Do Not Say — 절대 쓰면 안 되는 표현·주장
```

부정적 맥락 질문은 컴플레인 직전 단계라 **컴플레인과 같이 에스컬레이션 대상**으로 표시된다.

**빈칸을 추정으로 메우지 않는다.** 확인 안 된 수치·시점·계약 상대방, 타사 평가,
근거 없는 최상급, 미확정 계획 단정은 기본 Do Not Say 항목이다.

## 개인정보·스타일

회신 목록·요약은 익명 코드(`기자 #A3F1`)+매체로. 답장 초안 인사말은 "기자님",
실명은 Gmail 회신 발송 시점에만 주입한다. 존댓말·간결·담백, 이모지 금지, "감사합니다"는 1회.

## 절대 하지 말 것

- 수신거부 요청에 설득·재발송 시도
- 사실오류 지적에 방어 대응 / 사람 확인 없이 컴플레인 종결
- 확인 안 된 수치·계획을 답장에 채워 넣기
- 인터뷰·자료 요청 24시간 초과 방치 · 요청하지 않은 홍보자료 끼워넣기
