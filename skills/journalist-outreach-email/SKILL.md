# 기자 배포 메일 템플릿 (journalist-outreach-email)

기자는 하루 수백 통의 보도자료를 받는다. **3초 안에 "이건 기사가 된다"** 를
판단하게 만드는 것이 목표다. 아래 프레임을 그대로 채운다.

## 황금 구조 (6블록)

```
[제목]      25자 이내, 뉴스 헤드라인처럼. 회사명보다 '사건'을 앞세운다.
[1문장]     그 기자의 최근 기사 언급 → 왜 "당신에게" 보내는지 증명
[핵심 3줄]  무슨 일(What) / 왜 뉴스(Why now) / 숫자 근거(Proof)
[인용문]    대표 코멘트 1개 (기사에 바로 인용 가능하도록)
[자료]      보도자료 원문·이미지·미디어킷 링크
[CTA+거부]  인터뷰 제안 + 1줄 수신거부 문구
```

## 작성 규칙

**제목 (Subject)**
- 좋음: `[○○] 소상공인 매출관리 AI, 시드 10억 유치…"3개월 만에 가입 1만"`
- 나쁨: `보도자료 배포 요청드립니다` (누가 보냈는지·무슨 내용인지 0)
- 대괄호 `[회사명/보도자료]`로 분류 편의 제공, 핵심 숫자 1개 포함.

**첫 문장 = 개인화 훅 (가장 중요)**
- 반드시 그 기자의 `top_reference_title` 또는 beat를 언급.
- 예: "기자님의 '레드브릭하우스 카카오벤처스 투자' 기사 잘 읽었습니다. 유사한
  초기 투자 소식이 있어 먼저 전해드립니다."
- 이 한 줄이 없으면 스팸으로 분류된다. 절대 생략 금지.

**본문**
- 총 길이 250~400자. 스크롤 없이 한눈에.
- 역피라미드: 결론(숫자·성과) → 배경 → 의미.
- 형용사·수식어 최소화. 기자는 '팩트'를 원한다.
- 링크는 텍스트로, 첨부는 링크로(대용량 첨부 금지).

**인용문**
- 큰따옴표로, 그대로 기사에 붙일 수 있게.
- "우리는 최선을 다하겠다" 류의 공허한 말 금지. 구체적 비전/숫자.

**CTA + 수신거부 (필수)**
- CTA: "추가 자료나 대표 인터뷰가 필요하시면 편하게 회신 주세요."
- 수신거부: "본 메일 수신을 원치 않으시면 회신으로 '수신거부'라고 남겨주세요.
  즉시 명단에서 제외하겠습니다." ← 컴플라이언스상 필수, 삭제 금지.

## 표준 템플릿 (변수 치환)

> **PII 규칙**: `{{기자성}}`과 수신자 이메일은 **Gmail 초안 생성(`mcp__Gmail__create_draft`)
> 시점에만** 치환·주입한다. 화면 검토용 출력에서는 인사말을 "기자님"으로 표시하고
> 기자 실명·이메일을 노출하지 않는다(익명 코드 `기자 #A3F1`+매체로 지칭).

```
제목: [{{회사명}}] {{핵심사건}}…"{{한줄성과}}"

{{기자성}} 기자님, 안녕하세요. {{보내는사람}}입니다.
기자님의 '{{기자_최근기사}}' 기사 잘 보았습니다. 관련해 먼저 전해드릴 소식이 있습니다.

{{회사명}}은(는) {{날짜}} {{핵심사건}}. {{숫자근거}}.
{{배경한줄}}. {{의미한줄}}.

{{대표직함}} {{대표명}}은 "{{인용문}}"라고 밝혔습니다.

· 보도자료 원문: {{링크}}
· 이미지/미디어킷: {{링크}}

추가 자료나 인터뷰가 필요하시면 편하게 회신 주세요.
바쁘신 데 읽어주셔서 감사합니다.

{{보내는사람}} 드림
{{연락처}} / {{회사명}}

──
본 메일 수신을 원치 않으시면 회신으로 '수신거부'라 남겨주세요. 즉시 제외하겠습니다.
```

## beat별 앵글 조정

| 기자 beat | 강조할 것 | 피할 것 |
|---|---|---|
| 투자/벤처 | 라운드·투자사·밸류·성장률 | 제품 기능 나열 |
| IT/제품 | 기능·사용성·기술 차별점 | 재무 수치 위주 |
| 유통/커머스 | 판매·입점·소비 트렌드 | 기술 스펙 |
| 정책/공공 | 사회적 의미·규제·지원사업 | 홍보성 자화자찬 |
| 지역 | 지역 고용·상권 기여 | 전국 단위 일반론 |

## 개인화 자동화 규칙 (배포 시)

기자 N명 배포 시 각 메일은 **최소 제목1 + 첫문장1**을 서로 다르게. 나머지 본문은
공유 가능하나, beat가 다르면 앵글 문단도 교체. 완전 동일 메일 대량발송 금지.

## 팔로업 메일 (Pro)

무응답 기자에게 보내는 리마인더는 이 템플릿을 재사용하지 않는다 — **새 정보 1개를 앞세운
4줄 초단문 프레임**과 D+7 규칙은 Pro 스킬 `follow-up-scheduler`(Growth 이상)를 따른다.

## 체크리스트 (발송 전)

- [ ] 제목에 핵심 숫자 1개 있는가
- [ ] 첫 문장이 그 기자 기사/beat를 언급하는가
- [ ] 본문 400자 이내인가
- [ ] 인용문이 바로 인용 가능한가
- [ ] 수신거부 문구가 있는가
- [ ] 팩트/숫자가 검증되었는가
