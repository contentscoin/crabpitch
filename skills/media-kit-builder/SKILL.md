# 미디어킷 빌더 (media-kit-builder)

미디어킷은 기자가 회사를 소개할 때 **그대로 인용·발췌**하는 공식 자료다.
이 스킬은 사용자를 인터뷰하듯 **한 번에 한 가지만** 물어보며 빈칸을 채워
완성도 높은 미디어킷을 만든다. 소상공인·1인 창업가도 30분 안에 완성할 수 있게 돕는다.

## 진행 방식 (인터뷰 원칙)

1. **한 번에 질문 하나.** 폭탄 질문 금지. 답하기 쉽게 예시를 곁들인다.
2. **모르면 대신 초안을 써준다.** "이렇게 써봤는데 맞나요?" 식으로 확인받아 진행.
3. **팩트는 근거를 묻는다.** 숫자는 출처/기준 시점을 함께 기록(과장 방지).
4. 섹션이 끝날 때마다 **진행률**을 보여준다(예: 3/8 완료).
5. 전체가 끝나면 조립 → 검토 → 파일 산출(문서/PDF/랜딩).

## 미디어킷 8개 섹션 (수집 순서)

### 1. 한 줄 소개 (Boilerplate)
회사를 한 문장으로. 모든 보도자료 하단에 들어가는 공식 소개문.
- 질문: "회사를 처음 듣는 사람에게 한 문장으로 설명한다면?"
- 예: "○○는 소상공인을 위한 AI 매출관리 SaaS로, 2024년 설립되어 전국 1만 개 매장이 사용 중입니다."
- 체크: 무엇을 하는 회사인지 + 규모/시점 숫자 1개.

### 2. 핵심 메시지 3가지 (Key Messages)
기자·독자가 기억했으면 하는 메시지 3개. 모든 커뮤니케이션의 뼈대.
- 질문: "이 회사에 대해 딱 3가지만 기억된다면 무엇이길 바라나요?"
- 각 메시지는 '주장 + 근거' 세트로.

### 3. 팩트시트 (Fact Sheet)
기자가 표로 쓸 핵심 숫자·정보. 반드시 검증 가능하게.
| 항목 | 내용 | 근거/시점 |
|---|---|---|
| 설립 | | |
| 대표 | | |
| 사업 분야 | | |
| 주요 제품/서비스 | | |
| 이용자/매출/성장 지표 | | (기준 시점 필수) |
| 투자/수상 이력 | | |
| 임직원 수 | | |
| 본사 위치 | | |
| 홈페이지·SNS | | |

### 4. 회사 스토리 (Narrative)
창업 계기 → 문제의식 → 해결 → 현재 → 비전. 기사의 '스토리 라인' 재료.
- 질문 순서: "왜 이 사업을 시작했나요?" → "어떤 문제를 풀고 있나요?" →
  "어떻게 다른가요?" → "지금까지의 성과는?" → "3년 뒤 목표는?"

### 5. 대표/창업자 프로필 (Spokesperson)
인터뷰 섭외와 인물 기사용.
- 이름·직함·경력 3줄·사진·인터뷰 가능 주제·대표 인용문 2개.

### 6. 인용문 뱅크 (Quote Bank)
기자가 골라 쓸 수 있는 공식 코멘트 3~5개. 주제별로.
- 제품/비전/시장/사회적 의미 각 1개 이상. 바로 인용 가능한 완성형 문장.

### 7. 비주얼 자산 (Visual Assets)
- 로고(가로/세로, 배경 투명 PNG), 대표 사진, 제품 스크린샷/사진, 인포그래픽.
- 각 파일: 고해상도 링크 + 사용 가이드(색상 코드, 여백 규칙) + 저작권 표기.
- 없으면: 무엇을 준비해야 하는지 체크리스트 제공. (이미지 생성 필요 시 별도 안내)

### 8. 연락처 (Media Contact)
- 홍보 담당자 이름·이메일·전화·응대 가능 시간.
- 기자 문의 전용 창구 명시.

## 조립 & 산출

수집이 끝나면 다음 형태로 조립한다(사용자 선택):
- **문서(.md/.docx)**: 기자 배포용 표준 미디어킷 (docx 스킬 연동)
- **PDF**: 첨부·다운로드용 (pdf 스킬 연동)
- **웹 프레스킷(HTML)**: 링크로 공유하는 상시 미디어킷 페이지 (아티팩트로 영구 저장)
- **보일러플레이트 스니펫**: 보도자료 하단에 붙이는 공식 소개 문단

산출 후 `press-distribution` 스킬로 넘겨 배포 메일의 첨부/링크로 사용한다.
§2 핵심 메시지와 §3 팩트시트는 Pro 스킬 `interview-prep`(Solo 이상)의 답변 브리지·숫자 카드
재료가 되므로, 인터뷰가 잡히면 최신화부터 한다.

## 품질 기준 (완성 판정)
- [ ] 8개 섹션 모두 채워짐
- [ ] 모든 숫자에 기준 시점·출처 있음
- [ ] 인용문 3개 이상, 바로 인용 가능
- [ ] 로고·대표사진 최소 확보 또는 준비 체크리스트 제공
- [ ] 보일러플레이트 1문장 확정
- [ ] 미디어 연락처 명시

## 절대 하지 말 것
- 한 번에 여러 질문 쏟아내기(사용자 이탈)
- 검증 안 된 숫자를 팩트시트에 넣기
- 과장·최상급 표현 남발("업계 1위" 등은 근거 없으면 금지)
