# 퀵스타트 — 처음부터 발송까지

크랩피치 스킬 팩을 처음 쓰는 분을 위한 단계별 가이드입니다.
전체 흐름은 **미디어킷(1회) → 보도자료 → 기자 배포 → 회신 응대** 4단계입니다.

## 0. 준비물

- ChatGPT · Claude · Gemini 중 **하나** (무료 플랜도 가능, 문안 작성까지는 동일)
- 본인 Gmail 계정 (발송은 항상 본인 메일로 — BYO-Email)
- (선택) CrabPitch MCP 키 — 채팅에서 크랩피치 도구를 부르려면. 무료 플랜은 보도자료 작성 도구까지, 기자 매칭은 Solo 이상

## 1. 스킬 설치 (플랫폼별 1회)

### Claude 웹/데스크톱
1. `skills/` 폴더의 4개 `SKILL.md`를 내려받습니다.
2. 프로젝트를 하나 만들고 **프로젝트 지식**에 4개 파일을 업로드합니다.
   (또는 설정 → 기능에서 스킬로 추가)
3. 새 채팅에서 "보도자료 써줘"라고 말해 발동을 확인합니다.

### ChatGPT
1. **GPT 만들기**(커스텀 GPT)를 엽니다.
2. Instructions에 README의 **통합 부트스트랩 프롬프트**를 붙여넣습니다.
3. Knowledge에 4개 `SKILL.md`를 업로드합니다. (웹 검색이 켜져 있으면 URL만으로도 동작)
4. 저장 후 "이 소식 알리고 싶어"로 확인합니다.

### Gemini
1. **Gem 만들기**를 엽니다.
2. 지침에 통합 부트스트랩 프롬프트를 붙여넣고 저장합니다.
3. Google Workspace 연동을 켜면 6단계에서 Gmail 초안까지 이어집니다.

> 설치가 번거로우면: 새 채팅에 통합 프롬프트를 그냥 붙여넣어도 그 대화 동안은 동일하게 동작합니다.

## 2. 미디어킷 만들기 (처음 1회, 10분)

```
미디어킷 만들어줘
```

AI가 인터뷰하듯 8개 섹션(회사 한 줄 소개 → 핵심 메시지 → 팩트시트 → 스토리 →
대표 프로필 → 인용문 → 비주얼 → 연락처)을 하나씩 물어봅니다. 결과물은 저장해 두고
보도자료 쓸 때마다 재사용합니다.

## 3. 보도자료 쓰기 (소식이 생길 때마다)

```
보도자료 써줘. 우리는 [회사명], 이번에 [소식]. 수치는 [숫자 근거].
```

- 부족한 항목(5W1H·수치·인용문)은 AI가 하나씩 물어봅니다.
- 결과: 역피라미드 3문단 본문 + 서로 다른 앵글의 **헤드라인 3안**(사실/숫자/트렌드).

## 4. 기자 매칭 + 배포 메일

```
이 보도자료를 기자에게 뿌려줘
```

매칭 소스는 상황에 따라:
- **CrabPitch MCP 연결됨** → `crabpitch_match_journalists`로 후보를 바로 뽑습니다(익명 코드 표시).
- **OpenCrab MCP 연결됨** → OpenCrab 온톨로지에서 매칭.
- **둘 다 없음** → 갖고 있는 기자 리스트를 붙여넣으면 점수표(40/25/15/15/5)로 정렬해 줍니다.

기자별 개인화 메일(6블록: 호칭→후킹→핵심→수치→자료→수신거부)이 만들어집니다.

## 5. 승인 게이트 — 반드시 사람이 결정

AI는 **절대 스스로 발송하지 않습니다.** 대상 명단과 메일을 확인하고
"이 명단으로 진행해"라고 명시적으로 승인해야 다음 단계로 갑니다.
빼고 싶은 기자는 "기자 #A3F2 빼줘"처럼 코드로 지시합니다.

## 6. Gmail로 발송

- **Gmail MCP/Workspace 연동 시**: `언론홍보` 라벨에 기자별 초안이 자동 생성됩니다.
  Gmail에서 최종 확인 후 직접 보내기를 누릅니다.
- **연동 없음**: 만들어진 제목·본문을 복사해 본인 Gmail에서 보냅니다.
  (받는 사람마다 개별 발송 — 단체 BCC 금지)

라벨 설정 방법 → [`GMAIL-SETUP.md`](./GMAIL-SETUP.md)

## 7. 회신 오면

```
기자 답장 왔어: "[회신 내용 붙여넣기]"
```

7유형(인터뷰 요청/자료 요청/확인 질문/게재 통보/보류/수신거부/컴플레인)으로 분류하고
유형별 답장 초안을 만듭니다. **수신거부는 즉시 명단에서 제외**하고 다시는 보내지 않습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 스킬이 발동 안 함 | 트리거 문구("보도자료 써줘" 등)를 정확히 말하거나, SKILL.md 본문을 채팅에 직접 붙여넣기 |
| AI가 URL을 못 읽음 | 웹 접근이 없는 환경 — SKILL.md 파일 내용을 복사해 붙여넣기 |
| 기자 실명이 출력됨 | "기자 정보는 익명 코드로만 표시해"라고 재지시 (스킬 규칙 위반 상태) |
| MCP 도구가 안 보임 | 키가 `cp_mcp_…` 형식인지 확인 → [`MCP-SETUP.md`](./MCP-SETUP.md) |
| 매칭·회신 분류 도구만 안 보임 | 무료 플랜입니다. 채팅에서는 보도자료 작성만 열립니다 — **해당 기능은 웹앱에서 무료로 이용**하거나 Solo 이상으로 업그레이드 |
