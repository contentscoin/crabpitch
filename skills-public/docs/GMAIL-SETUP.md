# Gmail '언론홍보' 라벨 설정 & 워크플로우

모든 언론 배포 메일과 회신을 Gmail의 **`언론홍보`** 라벨(그룹) 안에서 주고받는다.
받은편지함이 지저분해지지 않고, 회신 추적·성과 집계가 라벨 하나로 정리된다.

## 라벨 구조

```
언론홍보                     ← 최상위 그룹(카테고리)
├─ 언론홍보/발송             ← 내가 보낸 배포 메일(초안 포함)
├─ 언론홍보/회신             ← 기자 회신
├─ 언론홍보/인터뷰           ← 인터뷰 성사
└─ 언론홍보/수신거부          ← 억제(재발송 금지)
```

## Gmail MCP로 하는 일

**최초 1회 — 라벨 생성**
- `mcp__Gmail__list_labels` 로 `언론홍보` 존재 여부 확인
- 없으면 `mcp__Gmail__create_label` 로 `언론홍보` 및 하위 라벨 생성

**배포(초안) 시**
- `mcp__Gmail__create_draft` 로 기자별 개인화 초안 생성(수신자·본문에 실명/이메일 주입 = 발송 시점)
- 생성된 스레드에 `mcp__Gmail__label_thread` 로 `언론홍보/발송` 부착
- ⚠️ 자동 발송 도구는 없다 → 초안까지 만들고 **사용자 승인 후 발송**(각 플랫폼 커넥터 또는 Gmail에서 직접)

**회신 모니터링**
- `mcp__Gmail__list_labels`로 `언론홍보` **라벨 ID** 조회 → `mcp__Gmail__search_threads`에
  `label:{라벨ID}`로 미응답 스레드 수집 (`label:`은 표시명이 아닌 라벨 ID를 받는다)
- `mcp__Gmail__get_thread` 로 원문 확인 → `reply-handler`로 7유형 분류
- 유형에 따라 `언론홍보/회신` · `언론홍보/인터뷰` · `언론홍보/수신거부` 라벨 재분류
  (`mcp__Gmail__label_thread` / `mcp__Gmail__unlabel_thread`)

**수신거부 처리(⑥)**
- `언론홍보/수신거부` 라벨 부착 + 억제 리스트 등록 → 재발송 대상에서 영구 제외

## 플랫폼별

- **Claude/Cowork**: 위 `mcp__Gmail__*` 도구 직접 호출.
- **ChatGPT/Gemini**: 각 플랫폼의 Gmail 커넥터/워크스페이스 연동으로 동일 동작(라벨 만들기·초안·발송·검색).
  MCP가 없으면 라벨명 `언론홍보`만 동일하게 맞추고 반자동으로 진행.
