# 기자 배포 오케스트레이터 (journalist-outreach)

보도자료(→ `press-release-writer`) 또는 아이디어를 받아 아래 5단계를 **순서대로, 사용자 확인을 받으며** 진행한다.

```
① 보도자료 확정 → ② 기자 매칭 → ③ 개인화 메일 초안 → ④ 동의·승인 게이트 → ⑤ Gmail '언론홍보' 발송·추적
```
절대 사용자 승인 없이 실제 메일을 발송하지 않는다. 기본 산출물은 항상 초안(draft)이다.

## ⛔ 두 가지 필수 원칙

**A. 기자 개인정보 비노출 (`docs/PRIVACY.md`)**
- 기자 **실명·이메일·연락처는 화면/응답/리스트/표에 절대 출력하지 않는다.**
  익명 코드(`기자 #A3F1`) + 매체 + beat + 신뢰도 + 적합도만 노출.
- 실제 이메일·실명은 **⑤ 실제 발송 시점**의 Gmail 수신자(To)·본문 인사말에만 주입한다.

**B. 컴플라이언스**
- 기자 데이터는 `mailing_status: candidate`(발송 미승인) 전제.
- 발송은 항상 **사용자 명시 승인** 후. 메일 하단에 **수신거부 문구** 필수.
- 동일 기자 **7일 내 재발송 금지**. 수신거부 회신은 **억제 리스트** 영구 등록(→ `reply-handler`).
- 발송은 **사용자 본인 Gmail(BYO-Email)**, Gmail **`언론홍보`** 라벨 안에서.

## ② 기자 매칭

주제 태그를 기자 온톨로지 쿼리로 변환한다.
- **OpenCrab MCP 연결 시** `opencrab_query`(팩: `korean-journalist-contact-index-v2`)로 조회.
- **미연결 시** 사용자가 붙여넣은 리스트를 동일 스키마로 정규화.

### 적합도 점수(0~100)
| 신호 | 배점 | 기준 |
|---|---|---|
| beat 일치 | 40 | 주제 ↔ beat_primary 정확 40 / 인접 25 |
| 최근 유사 기사 | 25 | top_reference가 유사 주제 |
| 기사 활동량 | 15 | reference_article_count |
| 연락처 신뢰도 | 15 | high 15 / medium 8 / low 3 |
| 매체 급 | 5 | 타깃 독자 적합성 |

**출력은 익명 코드로.** 예:
> **기자 #A3F1 · 지디넷코리아 · 플랫폼/핀테크 · 신뢰도 high — 87점**
> 이유: 최근 유사 투자유치 기사 다수, 투자 앵글 최적. (※ 실명/이메일 비표시)

`신뢰도 low`이거나 beat 불일치는 기본 제외.

## ③ 개인화 메일 초안 (황금 6블록)
```
[제목]   25자, '사건'을 앞세우고 핵심 숫자 1개
[1문장]  그 기자의 최근 기사/beat 언급(무작위 발송 아님을 증명) — 실명은 쓰지 않고 기사/분야로
[핵심3줄] 무엇 / 왜 뉴스 / 숫자 근거
[인용문] 대표 코멘트 1개(기사에 바로 인용 가능)
[자료]   보도자료·이미지·미디어킷 링크
[CTA+거부] 인터뷰 제안 + 1줄 수신거부 문구(필수)
```
- 초안 단계 본문은 인사말을 **"기자님"**으로(실명 미포함). 실명은 ⑤ 발송 시 주입.
- beat별 앵글 조정: 투자→라운드·성장률 / 제품→기능·차별점 / 유통→판매·트렌드 / 정책→사회적 의미.
- 완전 동일 메일 대량발송 금지(제목1 + 첫문장1은 기자별로 다르게).

## ④ 동의·승인 게이트
발송 직전 사용자에게 보여주고 명시 확인:
1. 최종 수신자 수(코드로 표시, 개별 제외 가능)
2. 발송 통수 vs 한도(무료 월 10통 등)
3. 수신거부 문구 포함 여부
4. "Gmail 초안 생성 / 지금 발송(사용자 확인 후) / 취소"

## ⑤ Gmail '언론홍보' 발송·추적 (`docs/GMAIL-SETUP.md`)
- 최초 1회 `mcp__Gmail__create_label`로 `언론홍보`(+하위) 생성.
- 기자별 `mcp__Gmail__create_draft`(수신자·본문에 실명/이메일 = **여기서만** 주입).
- `mcp__Gmail__label_thread`로 `언론홍보/발송` 부착.
- 실제 발송은 사용자 승인 후(자동 발송 도구 없음). 회신은 `reply-handler`가 `언론홍보`에서 모니터링.

## 절대 하지 말 것
- 실명·이메일·연락처 화면 노출 · 승인 없는 실발송 · 신뢰도 low 발송 · 7일 내 재발송 · 수신거부 문구 없는 메일 · 팩트체크 안 된 숫자
