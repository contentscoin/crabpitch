# 미디어킷 빌더 (media-kit-builder)

미디어킷은 기자가 회사를 소개할 때 그대로 인용·발췌하는 공식 자료다.
사용자를 인터뷰하듯 **한 번에 한 가지만** 물어 빈칸을 채운다. 소상공인도 30분 안에 완성.

## 진행 원칙
1. **한 번에 질문 하나.** 답하기 쉽게 예시를 곁들인다.
2. **모르면 대신 초안을 써준다.** "이렇게 써봤는데 맞나요?"로 확인.
3. **숫자는 근거·기준 시점을 함께 기록**(과장 방지).
4. 섹션마다 진행률 표시(예: 3/8).

## 8개 섹션 (수집 순서)
1. **보일러플레이트** — 회사를 한 문장으로(무엇을 하는가 + 규모/시점 숫자 1개).
2. **핵심 메시지 3가지** — 기억됐으면 하는 것 3개, 각 '주장 + 근거'.
3. **팩트시트** — 설립·대표·사업분야·주요제품·이용자/매출/성장·투자/수상·임직원·본사·홈페이지(근거/시점 필수).
4. **회사 스토리** — 창업 계기 → 문제 → 해결 → 현재 → 3년 비전.
5. **대표/창업자 프로필** — 이름·직함·경력 3줄·인터뷰 가능 주제·대표 인용문 2개.
6. **인용문 뱅크** — 제품/비전/시장/사회적 의미 각 1개 이상, 바로 인용 가능한 완성형.
7. **비주얼 자산** — 로고(투명 PNG)·대표 사진·제품 이미지 링크 + 사용 가이드(없으면 준비 체크리스트).
8. **미디어 연락처** — 홍보 담당자 창구(이름·연락 수단·응대 시간).

## 산출 (사용자 선택)
- 문서(.md/.docx) · PDF · 웹 프레스킷(HTML 링크) · 보일러플레이트 스니펫
- 완성 후 `journalist-outreach`로 넘겨 배포 메일의 첨부/링크로 사용.
