# 미디어킷 빌더 (media-kit-builder)

미디어킷은 기자가 회사를 소개할 때 그대로 인용·발췌하는 공식 자료다.
사용자를 인터뷰하듯 **한 번에 한 가지만** 물어 빈칸을 채운다. 소상공인도 30분 안에 완성.

## 0. 시작 전 — 플랜 확인 (MCP 사용 시)

CrabPitch MCP에 연결된 상태라면 `crabpitch_status`의 `skills`에 `media-kit-builder`가
있는지 본다. 없으면(무료 플랜) 채팅에서 진행하지 말고 이렇게 안내하고 **멈춘다**:

> 채팅에서의 미디어킷 작성은 Solo 이상 플랜에서 열립니다.
> **미디어킷 자체는 CrabPitch 웹앱에서 무료 플랜으로도 만들 수 있습니다** —
> 웹앱의 미디어킷 화면에서 섹션을 채우면 완성도 점수와 갭 리포트까지 그대로 나옵니다.

MCP에 연결돼 있지 않다면 플랜과 무관하게 그대로 진행한다(이 스킬은 서버 자원을 쓰지 않는다).

## 진행 원칙
1. **한 번에 질문 하나.** 답하기 쉽게 예시를 곁들인다.
2. **모르면 대신 초안을 써준다.** "이렇게 써봤는데 맞나요?"로 확인.
3. **숫자는 근거·기준 시점을 함께 기록**(과장 방지).
4. 섹션마다 진행률 표시(예: 3/8).

> 좋은 프레스킷은 소개서 PDF 한 개가 아니라, 기자가 기사 작성에 필요한 텍스트·시각 자산을
> 검색하고 내려받을 수 있는 **허브**다.

## 10개 섹션 (수집 순서 — CrabPitch 완성도 채점 기준과 동일)
1. **한 문장 회사 정의** + 80~120자 요약.
2. **회사 개요** — 설립연도·본사·시장·핵심 수치.
3. **창업 배경과 주요 연혁.**
4. **대표 제품·서비스 설명.**
5. **창업자·경영진 약력** + 고해상도 인물 사진.
6. **비주얼 자산** — 로고(투명 PNG)·제품 사진·스크린샷·영상 B-roll.
7. **최근 보도자료와 주요 언론 보도.**
8. **표준 회사 소개문(보일러플레이트)** — 100단어 안팎.
9. **자산 사용 규정과 사진 크레딧.**
10. **언론 문의 담당자** — 이름·이메일·전화번호.

여기에 **핵심 메시지 3가지**(각 '주장 + 근거')와 **인용문 뱅크**(제품/비전/시장 각 1개 이상,
바로 인용 가능한 완성형)를 함께 모은다.

### 팩트시트는 보도자료의 대조 기준이다
`press-release-writer`가 본문 수치를 팩트시트와 대조한다. **팩트시트에 없는 숫자가 본문에
나오면 지적된다.** 그러니 숫자는 여기에 근거·기준 시점과 함께 먼저 등록한다.
보일러플레이트도 마찬가지로 **여기가 단일 소스**다 — 배포본에서 고쳐 쓰지 않는다.

### ⑨ 자산 사용 규정 필수 4항
- 사용 허용 범위(보도 목적 한정 여부)
- 수정·변형 금지 사항(로고 비율·색상 변경 등)
- 저작권·크레딧 표기 방법
- 상표 사용 제한 및 추가 자산 문의처

### 파일명 규칙 (검사 대상)
`[기업명]-[제품명]-[핵심키워드].png` — 하이픈으로 **3토큰 이상**, 그중 **의미 있는 토큰 2개 이상**.

- ❌ `KakaoTalk_2026….jpg` · `스크린샷.png` · `IMG-1234-final.png` (전부 일반 토큰)
- ✅ `crabpitch-dashboard-matching.png`

`img`·`screenshot`·`final`·`copy`·`untitled` 같은 일반 단어와 순수 숫자는 의미 토큰으로
세지 않는다. 회사명이 파일명에 들어가면 기자가 폴더에서 바로 찾는다.
Alt 텍스트는 주관적 수식어 없이 누가·무엇인지 단문으로, 캡션은 이미지 아래 1줄로 본문
핵심 키워드와 맞춘다.

## 산출 (사용자 선택)
