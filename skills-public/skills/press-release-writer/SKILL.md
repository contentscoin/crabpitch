# 보도문 작성 (press-release-writer) · v2

기자는 하루 수백 통을 받고, 생성형 AI는 그중 **구조가 잡힌 것만** 인용한다.
이 스킬은 사용자 입력을 표준 보도자료로 조립하고, 배포 전에 표시광고법 체크를 통과시킨다.

> **규범 정본은 `convex/lib/pressGuide.ts`다.**
> 이 문서의 구조·수치·금칙어·판정 기준은 전부 그 상수의 문서 뷰다. 값이 어긋나면 **코드가 맞다.**
> 상수를 고칠 때 이 문서와 `references/`를 같은 PR에서 갱신한다.

상세 표는 분리해 두었다 — 필요할 때만 열어 본다.

| 파일 | 언제 읽나 |
|---|---|
| [`references/structure.md`](./references/structure.md) | 표준 구조 9블록·리드 3문장·문장 길이 등 작성 전략 수치 |
| [`references/geo.md`](./references/geo.md) | GEO 12규칙·Key Takeaways·FAQ·이미지 자산 규칙 |
| [`references/compliance.md`](./references/compliance.md) | 표시광고법 L1/L2/L4 금칙어·대체 표현·인용 포맷·게이트 판정 |

## 산출 규격이 두 가지다 — 먼저 어느 경로인지 밝힌다

| 경로 | 산출 | 규격 |
|---|---|---|
| **스킬 경로**(이 문서) | 표준 구조 **풀 템플릿** | 제목·부제 2개·리드 3문장·바디 2~3개·임원 코멘트·보일러플레이트·미디어 문의 + GEO 레이어 |
| **크랩피치 웹 폼**("AI 다듬기") | 폼 저장용 **본문** | 300~500자. 내부 순서는 리드 → 배경 → 인용 → 보일러플레이트 |

웹 폼의 300~500자는 크랩피치 폼의 기존 산출 규격이며 **지식 팩 근거가 아니다**(`CRABPITCH_FORM_BODY_CHARS`).
둘을 섞지 않는다. 사용자가 "웹앱에 붙여 넣을 것"이라고 하면 폼 규격으로, 그 외에는 풀 템플릿으로 쓴다.

## STEP 0 — 입력 확보 (없으면 한 번에 하나씩 질문)

- [ ] **핵심 한 줄**: 무슨 일이 일어났나
- [ ] **주체**: 회사/브랜드/인물의 **공식 표기**(띄어쓰기·영문 병기까지)
- [ ] **언제·어디서**
- [ ] **뉴스 밸류**: 왜 지금 기사가 되나
- [ ] **숫자·근거**: 값 + **출처/집계 기준/조사 시점**을 함께. 출처 없는 숫자는 받지 않는다
- [ ] **임원 코멘트 재료**: 실명·직책 + 결정 이유 / 시장 해석 / 향후 계획 중 1개
- [ ] **보일러플레이트**: 있으면 미디어킷의 것을 그대로 가져온다(단일 소스)
- [ ] **자료 링크**: 이미지·미디어킷·원문
- [ ] **엠바고**: 해제 시각이 있으면 여기서 확정한다

**공식 표기 체크리스트**(회사마다 다르므로 사용자에게서 받는다 — 임의로 만들지 않는다)

- [ ] 회사명 국문/영문 표기와 띄어쓰기
- [ ] 제품·서비스 공식 표기
- [ ] 직책 표기 구조(약어 사용 여부)
- [ ] 수치 표기 규칙(단위·자릿수 병기)

검증할 수 없는 수치는 **창작하지 말고 `[확인 필요]`로 남긴 뒤** 근거 자료를 요청한다.
배포본에 `[확인 필요]`가 남아 있으면 그 자체가 체크리스트 위반이다.

## STEP 1 — 개요 승인 (게이트 ①)

초안을 쓰기 전에 아래를 **한 화면으로 보여주고 승인**을 받는다. 여기서 방향이 틀리면 뒤가 전부 헛일이다.

1. **헤드라인 3안** — 30자 이내, 회사명보다 '사건'을 앞세우고 핵심 숫자 1개.
   톤을 다르게: (a) 사실형 (b) 성과·숫자형 (c) 의미·트렌드형.
   GEO를 노린다면 (c)를 **검색 질문·해결책 형태**로 만든다.
2. **부제 2안** — 각 40자 이내, 제목이 못 담은 보조 포인트.
3. **[3줄 요약](Key Takeaways)** — 정확히 3줄, 각 줄에 검증 가능한 사실 1개.
4. **핵심 메시지 3개 이내** — 그 이상은 아무것도 안 남는다.
5. **확보된 수치와 출처 목록** — `[확인 필요]`가 몇 개인지 함께 보고.

승인 없이 STEP 2로 넘어가지 않는다.

## STEP 2 — 본문 작성

구조와 수치 규범은 [`references/structure.md`](./references/structure.md), GEO 레이어는
[`references/geo.md`](./references/geo.md)를 따른다. 작성 중 놓치기 쉬운 것만 다시 적는다.

- [ ] 리드는 **정확히 3문장** — ①발표 사실 ②배경·차별점 ③기대효과·다음 스텝. 5W1H를 여기서 끝낸다.
- [ ] 첫 **100단어** 안에 누가·무엇을·언제·수치가 전부 들어갔다.
- [ ] 한 문장 **50자 지향 · 80자 상한**, 한 문단 **4문장 이내**. 복문은 쪼갠다.
- [ ] 바디마다 검색 의도가 담긴 소제목(H2/H3)을 단다. 줄글 나열 금지.
- [ ] 임원 코멘트는 **실명·직책** + 제목을 반복하지 않는 새 정보 1개.
- [ ] 보일러플레이트는 **80~120단어**, 미디어킷의 것과 **같은 문장**이어야 한다.
- [ ] 홍보성 형용사를 지우고 검증 가능한 수치로 바꿨다.

## STEP 3 — 컴플라이언스 체크 (게이트 ②)

[`references/compliance.md`](./references/compliance.md)의 L1·L2·L4를 순서대로 훑고 결과를 표로 보고한다.
크랩피치 웹앱을 쓰는 경우 같은 상수를 쓰는 결정적 lint(`convex/lib/pressLint.ts`)가 폼에서 배지로 표시한다.
CrabPitch MCP(유료 키)가 연결돼 있으면 `crabpitch_press_guide`로 가이드 원문 조회와 초안 검사를 함께
받을 수 있다(`section`: structure / writing / geo / adlaw / presskit / all, `draft`·`title` 선택).

**판정** (`GATE_THRESHOLDS`)

| 조건 | 판정 | 행동 |
|---|---|---|
| critical ≥ 1 | **fail** | 산출 중단. 아래 서브루틴 실행 |
| high ≥ 3 또는 medium ≥ 5 | **warn** | 사용자에게 목록을 보여주고 승인받은 뒤 진행 |
| 그 외 | pass | 진행 |

**critical 처리 서브루틴**

1. 위반 부분과 **대체 표현**을 함께 제시한다.
2. 재작성은 **최대 2회**까지 시도한다.
3. 2회 뒤에도 남으면 자동으로 고치지 말고 **사용자에게 에스컬레이션**한다 — "이 주장은 근거 자료가 없으면 쓸 수 없습니다. 근거를 주시겠어요, 아니면 문장을 뺄까요?"
4. **critical은 자동 치환하지 않는다.** 근거 없는 '최초'·'100%'·'절대 보장'은 표현을 바꾼다고 사실이 되지 않는다.

⚠️ 이 체크는 **표시·광고의 공정화에 관한 법률 계열만** 다룬다. 언론중재법(정정·반론보도)은
범위 밖이며, **이 스킬은 법률 검토를 대체하지 않는다.** 분쟁 소지가 있으면 사용자에게 법률 검토를 권한다.

## STEP 4 — 산출

```
[헤드라인 3안 / 부제 2개]
[3줄 요약(Key Takeaways)]
[본문] 리드 3문장 → 바디 2~3개(소제목 포함) → 임원 코멘트 → 보일러플레이트 → 미디어 문의
[FAQ] 기자·독자가 실제로 물을 질문만 (문항 수 규정 없음)
[팩트 요약] 무엇 / 왜 뉴스 / 숫자와 출처
[체크리스트 결과] critical·high·medium 건수와 남은 `[확인 필요]`
```

- 엠바고가 있으면 **문서 최상단**에 해제 시각을 1줄로 적고, 자료 링크 블록에서 한 번 더 고지한다.
- 이미지가 있으면 파일명·Alt·캡션 규칙([`references/geo.md`](./references/geo.md))을 함께 안내한다.

## AI 실행 원칙

크랩피치는 **공용 LLM 키를 제공하지 않는다.** 웹앱의 AI 기능은 사용자 본인 키(BYOK)로,
채팅에서 쓸 때는 사용자 본인 챗에서 실행된다. 키가 없으면 AI 단계는 건너뛰고 수동 절차로 진행한다.

## 절대 하지 말 것

- 검증 안 된 숫자·수상·최초 주장 삽입 (모르면 `[확인 필요]`)
- critical 위반을 자동으로 치환하고 넘어가기
- 배포본에 `[확인 필요]` 잔존
- 특정 회사 스타일북을 임의로 적용하기 — 공식 표기는 **사용자에게 받는다**
- "법률 검토를 대체한다"는 식의 안내
