# 표시광고법 체크 (L1 · L2 · L4)

> 정본은 **`convex/lib/pressGuide.ts`** — `L1_BANNED_TERMS`, `L2_SUPERLATIVES`,
> `L2_EVIDENCE_CONDITIONS`, `NUMBER_PATTERN`, `SOURCE_MARKERS`, `CITATION_FORMATS`,
> `GATE_THRESHOLDS`, `UNCODED_LEVELS`.
> 값이 어긋나면 코드가 맞다. 상수를 고칠 때 이 파일을 같은 PR에서 갱신한다.
>
> 크랩피치 웹앱에서는 같은 상수를 쓰는 결정적 lint가 동작한다 —
> **보도자료는 warn-only**(저장을 막지 않는다), **배포 메일은 critical이면 발송 차단**(`emailCompliance`).
> 도메인별 차등이며 모순이 아니다. 메일 발송은 되돌릴 수 없기 때문이다.

**엔진 원칙**: ① 규칙을 먼저 본다 ② LLM은 맥락만 판단한다 ③ critical을 제외하면 차단이 아니라 **대체 표현을 제안**한다.

법 근거는 **표시·광고의 공정화에 관한 법률**(비교광고는 제3조 부당비교광고)이다.
⚠️ **언론중재법(정정·반론보도)은 범위 밖**이며, 이 체크는 **법률 검토를 대체하지 않는다.**

## L1 — 금칙어

| 패턴 | 심각도 | 대체 표현 |
|---|---|---|
| (업계\|세계\|국내\|국내외) 최초 | **critical** | 범위와 출처를 병기한다. 예: "국내 ○○업계 최초(○○부 2026년 4월 자료 기준)" |
| 100% | **critical** | "대부분의 경우" 또는 측정 조건과 함께 실측치를 제시한다 |
| (절대\|무조건\|반드시) + (안전\|안심\|성공\|보장\|가능) | **critical** | "대체로·일반적으로" 등 조건부 표현 + 근거로 바꾼다 |
| 완전 무료 / 전액 무료 | high | "기본 무료(조건 확인)"처럼 조건을 함께 적는다 |
| 완벽한·완벽히 / 무결점 | high | "안정적인·완성도 높은" + 구체적 성능 수치 |
| 단연 / 타의 추종을 불허 | high | "독자적인·차별화된" + 무엇이 다른지 사실 기술 |

⚠️ **오탐 주의**: '모두·전부·반드시·절대'는 일상 문맥에서 매우 자주 쓰인다. 코드 검사는
**보장·안전·성공 등 단정 맥락과 붙어 있을 때만** 잡도록 스코프를 좁혀 두었다.
단어만 보고 정상 문장을 고치라고 요구하지 않는다 — 맥락을 읽는다.

## L2 — 최상급·순위 주장 (근거 필수)

| 패턴 | 심각도 | 대체 표현 |
|---|---|---|
| (업계\|국내\|세계) + (1위\|최고\|최대\|최장\|최저) | high | 조사기관·조사 시점·모집단을 병기한다(6개월 이내 자료) |
| 유일한 / 유일무이 | high | 확인한 범위를 명시한다. 예: "당사가 확인한 국내 사례 중" |
| (가장\|제일) + (빠른\|저렴한\|우수한\|뛰어난\|높은) | medium | 비교 대상과 측정 방법을 명시한다 |

**근거로 인정되는 조건 3가지** — 셋 중 하나라도 빠지면 L1(금칙어)으로 강등해 처리한다.

- [ ] 공신력 있는 기관의 통계·조사를 인용할 것
- [ ] 인용 자료가 **6개월 이내**일 것
- [ ] 본문에 출처를 명시할 것(예: "2026년 ○○ 조사 기준")

## L4 — 수치에 출처가 붙었는가

정량 표현(`%`, `배`, `만 명`, `명`, `건`, `위`, `억`, `천`, `원`, `달러` 등) 근처에
출처 표지가 없으면 위반이다.

**출처 표지**: 출처 · 기준 · 자료 · 조사 · 집계 · 발표 · 보고서 · 통계 · 인용 · "에 따르면" · source / according

같은 문장 또는 **바로 앞뒤 문장**에 표지가 있으면 통과로 본다(오탐 완화).

**인용 표기 포맷**

```
통계 인용   : "{기관} {년도} 조사에 따르면 {수치}"
리포트 인용 : "{조사기관} {리포트명} ({년도})"
타사 발표   : "{회사}는 {날짜} {내용}을 발표했다 ({출처 URL})"
```

## 판정 기준

| 조건 | 판정 | 행동 |
|---|---|---|
| critical ≥ 1 | **fail** | 출력 차단 → 재작성 최대 2회 → 남으면 사용자 에스컬레이션 |
| high ≥ 3 또는 medium ≥ 5 | **warn** | 사용자 승인 필수 |
| 그 외 | pass | 진행 |

**critical은 자동 치환하지 않는다.** 근거 없는 주장은 표현을 바꾼다고 사실이 되지 않는다 —
작성자가 근거를 대거나 문장을 빼야 한다.

## 코드 검사를 하지 않는 레벨

| 레벨 | 이름 | 이유 |
|---|---|---|
| L3 | 비교광고 | 경쟁사 엔티티 목록이 필요하고, 지식 팩 예시는 특정 산업 사업자 하드코딩이라 이식하지 않았다 → **모델이 맥락으로 판단**한다 |
| L5 | 내부자료 인용 | 사내 문서 저장소 전제가 크랩피치에 없다(사용자가 자기 회사 보도자료를 직접 쓰는 구조) |
| L6 | 스타일북 일관성 | 어휘가 사실상 전부 회사 고유 상수 → 범용 표기 통일 원칙만 지침화 |

L3은 코드가 잡지 않으므로 **작성자가 직접 본다**:
타사를 언급했다면 ① 비교 대상·기준·시점이 명확한가 ② 객관적으로 측정 가능한 항목인가
③ 상대를 깎아내리는 표현이 없는가를 확인하고, 하나라도 걸리면 비교 자체를 뺀다.
