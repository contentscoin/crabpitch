# 회신 응대 (reply-handler)

기자 회신은 관계의 시작이다. 빠르고 정확한 응대가 게재율을 좌우한다.
이 스킬은 Gmail **`언론홍보`** 라벨의 회신을 자동 분류하고 유형별 답장 초안을 만든다.

## ⛔ 개인정보 원칙
- 회신 목록·요약을 보여줄 때 기자 **실명·이메일을 노출하지 않는다.** `기자 #A3F1 · 지디넷` 처럼 코드로.
- 답장 초안 본문 인사말은 **"기자님"**으로. 실명은 **실제 회신 발송 시점**의 Gmail 본문에만 주입.

## 회신 수집 (Gmail MCP)
1. `mcp__Gmail__list_labels`로 `언론홍보` **라벨 ID** 조회 → `mcp__Gmail__search_threads`에 `label:{라벨ID}`로 미응답 스레드 수집(답장 알림 — `label:`은 표시명이 아닌 라벨 ID를 받는다).
2. `mcp__Gmail__get_thread` — 원문 파악 → 아래 7유형 분류.
3. 분류 후 `mcp__Gmail__label_thread` — `언론홍보/회신`·`언론홍보/인터뷰`·`언론홍보/수신거부` 재분류.
4. 유형별 `mcp__Gmail__create_draft`(`replyToMessageId`) 답장 초안 → 사용자 검토 후 발송.

**CrabPitch MCP 연결 시** 분류에 `crabpitch_classify`를 먼저 호출해도 된다(동일 7유형). 최종 발송·실명 주입은 Gmail에서만.

## 7유형 분류
| 유형 | 신호 | 우선순위 | 액션 |
|---|---|---|---|
| ① 인터뷰 요청 | "인터뷰", "통화 가능", "일정" | 🔴 즉시 | 일정 3안 + 대표 연결, `언론홍보/인터뷰` |
| ② 자료 요청 | "고화질", "추가 자료", "매출 자료" | 🔴 즉시 | 요청 자료만 정확히 |
| ③ 확인 질문 | "맞나요", "근거", "수치" | 🟠 당일 | 팩트+근거 링크만 |
| ④ 게재 통보 | "기사 나갔", 링크 | 🟢 감사 | 감사 회신 + 성과 집계 |
| ⑤ 보류/거절 | "이번엔 어렵", "다음 기회" | 🟢 정중 | 감사 + 다음 소식 예고 |
| ⑥ 수신거부 | "수신거부", "그만", "빼주세요" | ⚫ 즉시 | 억제 리스트 등록 + 사과 없는 정중한 확인, `언론홍보/수신거부` |
| ⑦ 부정/컴플레인 | 사실오류 지적, 항의 | 🔴 신중 | 사실 확인 → 정정, 방어 금지 |

## 유형별 답장 톤(요지)
- **인터뷰**: 빠르게, 선택지(일정 3안) + 대표 연결.
- **자료**: 군더더기 없이 요청한 것만.
- **확인 질문**: 팩트 + 근거. 홍보 문구 금지.
- **게재**: 진심 어린 감사 1회 + 다음 관계.
- **수신거부(핵심)**: 변명·설득·사과 없이 즉시 수용 + **억제 리스트 등록 + `언론홍보/수신거부` 라벨**. 예)
  `기자님, 알겠습니다. 명단에서 즉시 제외했습니다. 좋은 하루 보내세요.`
- **컴플레인**: 방어·감정 금지. 사실 확인 → 정정/사과.

## 응대 스타일
존댓말·간결·담백. 이모지/과한 감탄사 금지. "감사합니다"는 진심으로 1회. 회신 끝에 다음 관계의 여지.

## 절대 하지 말 것
