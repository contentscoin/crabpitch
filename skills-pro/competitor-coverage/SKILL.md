# 경쟁사 노출 비교 (competitor-coverage) — Growth 이상

경쟁사가 실린 매체는 **우리도 실릴 수 있는 매체**다. 이 스킬은 경쟁사 커버리지를
정찰 지도로 바꾼다 — 비방이 아니라 **빈틈 공략**이 목적이다.

## ⛔ 윤리 원칙 (가장 먼저)
- **경쟁사 비방·허위 비교 금지.** 수집한 정보는 우리 앵글 개발에만 쓴다.
- 기자에게 "경쟁사 말고 우리를 써달라"는 식의 피치 금지 — 기자는 그 순간 양쪽 다 거른다.
- 경쟁사 기사·기자 정보는 모두 **공개된 기사 지면**에서만 수집(사찰·비공개 정보 수집 금지).
- PII 원칙 동일: 매칭 후보 기자는 화면에 코드+매체로만 표시.

## ① 입력 확보
- 경쟁사 리스트(1~5개사) + 비교 기간(기본 최근 3개월) + 우리 회사의 같은 기간 게재 목록
  (campaign-report가 있으면 그대로 가져온다).

## ② 커버리지 수집 (웹 검색)
1. 웹 검색(WebSearch 등)으로 경쟁사별 검색: `"{경쟁사명}"` + 기간 필터,
   `"{경쟁사명}" 투자|출시|제휴`, `site:{주요 매체 도메인} "{경쟁사명}"`.
2. 기사마다 기록: 매체 · 기사 제목 · URL · 게재일 · 주제(투자/제품/인물/트렌드/위기) · 형태
   (단독/기획/보도자료 전재/인터뷰).
3. **보도자료 전재와 기획·단독을 구분**한다 — 전재는 배포망의 결과, 기획·단독은 관계의 결과.
   벤치마킹 가치는 후자가 훨씬 높다.
4. 검색 미지원 환경이면 사용자가 붙여넣은 기사 목록을 동일 스키마로 정규화.

## ③ 커버리지 매트릭스

```
            투자  제품  인물  트렌드  합계
우리          2    1    0     0      3
경쟁사 A      3    4    1     2     10
경쟁사 B      1    2    0     1      4
─ 매체별 표도 동일 형식(종합지/경제지/IT전문지/버티컬 × 회사)
```

## ④ 갭 분석 → 액션
| 발견 | 해석 | 액션 |
|---|---|---|
| 경쟁사만 실리는 매체 | 그 매체는 이 업계를 다룬다 = 우리도 후보 | 해당 매체·beat 기자 매칭(→ ⑥) |
| 경쟁사만 다루는 주제(예: 인물) | 우리는 그 유형 소재를 안 내보냄 | 소재 개발(대표 스토리 → media-kit-builder) |
| 우리만 실리는 매체 | 우리 강점 채널 | 관계 강화(엠바고 우선 제공 등) |
| 경쟁사 기획·단독 다수 | 기자 관계 격차 | 인터뷰·팔로업 강화(interview-prep, follow-up-scheduler) |

## ⑤ 뉴스재킹 앵글 (경쟁사 이슈에 얹기)
경쟁사발 이슈(대형 투자, 시장 리포트, 규제)가 뜨면 **업계 트렌드 프레임**으로 우리 앵글을 만든다.
- 좋음: "○○ 시장 커진다 — 우리는 이 지점이 다르다"(데이터 1개 필수).
- 금지: 경쟁사 실명 걸고 비교 우위 주장, 경쟁사 악재에 올라타기(역풍 최대).
- 산출: 앵글 3안 + 각 앵글에 맞는 beat → press-distribution으로 전달.

## ⑥ 신규 기자 타깃 발굴
경쟁사 기사를 쓴 기자 = 이 업계에 지면을 쓰는 현역 기자.
1. 수집한 기사에서 매체·지면 성격을 정리(바이라인 실명은 **화면에 옮기지 않는다**).
2. OpenCrab 연결 시 `opencrab_query`로 해당 매체·beat 기자를 조회해 press-distribution
   매칭 파이프라인에 코드로 합류시킨다. 미연결 시 매체·beat 리스트만 전달.
3. 이 기자들에게 보내는 첫 메일 훅은 "경쟁사 기사 언급"이 아니라 **그 기자의 업계 기사 자체**를
   언급한다(예: "○○ 시장 분석 기사 잘 읽었습니다").

## 산출물
```
[커버리지 매트릭스 (회사×주제, 회사×매체)]
[갭 3가지 + 각 갭의 액션]
[뉴스재킹 앵글 3안 (beat 지정)]
[신규 타깃: 매체·beat 리스트 (기자는 코드로)]
```
분기 1회 정기 실행을 권장 — 결과를 campaign-report에 첨부하면 "우리 vs 시장" 뷰가 된다.
