# 팔로업·예약 발송 (follow-up-scheduler) — Growth 이상

기자 게재의 상당수는 **두 번째 접촉**에서 나온다. 단, 스팸과 팔로업은 한 끗 차이다.
이 스킬은 컴플라이언스(7일 규칙) 안에서만 팔로업을 설계한다.

## ⛔ 팔로업 컴플라이언스 (절대 규칙)
1. **D+7 이후에만** — 동일 기자 7일 내 재발송 금지 규칙은 팔로업에도 그대로 적용된다.
2. **캠페인당 총 접촉 2회 상한** — 원 발송 1 + 팔로업 1. 두 번 무응답이면 이번 소재는 접는다.
3. **제외 대상**: 수신거부(억제 리스트) · 이미 회신한 기자(→ reply-handler가 담당) ·
   직전 다른 캠페인으로 7일 내 접촉한 기자.
4. **새 정보 1개 필수** — 원문 재전송·"확인하셨나요?"만 보내는 팔로업 금지.
5. PII 원칙 동일: 화면에는 기자 코드만, 실명·이메일은 Gmail 초안 생성 시점에만 주입.

## ① 팔로업 대상 선별

1. `mcp__Gmail__search_threads` — `label:언론홍보/캠페인/{캠페인명}`에서 **회신 없는 스레드** 추출.
2. 발송일 확인 → **D+7 경과분만** 후보로. 억제 리스트 대조 제거.
3. 후보를 코드로 제시: `기자 #A3F1 · 지디넷 · 원 발송 D+9 · 적합도 87` — 사용자가 개별 제외 가능.
4. campaign-report 관계 스코어가 있으면 게재 이력 기자(+5 이상)를 우선 배치.

## ② 팔로업 메일 프레임 (4줄 초단문)

```
[제목]  원 제목 재사용 금지. 새 정보를 앞세운 새 제목 (예: "…한 달 만에 2만 돌파, 후속 데이터 공유")
1줄: 지난 메일 참조 — "지난주 보내드린 {{소식}} 관련, 짧게 한 가지만 보탭니다."
2줄: 새 정보 — 후속 성과/새 데이터/업계 이슈 연결 중 1개 (팩트체크 필수)
3줄: 가벼운 CTA — "기사 각도가 안 맞으면 편히 무시하셔도 됩니다. 자료 필요하시면 회신 주세요."
4줄: 수신거부 문구 (필수, 원 메일과 동일)
```
- 죄책감 유발 금지("바쁘신 건 알지만…" 남발, "왜 답이 없으신지" 류).
- 인사말은 "기자님" — 실명은 발송 시점 주입(journalist-outreach-email 규칙 동일).

## ③ 발송 타이밍 최적화

| 권장 | 회피 |
|---|---|
| 화~목 09:00~11:00 (아침 회의 후, 마감 전) | 월요일 오전(주간회의) · 금요일 오후 |
| 점심 직후 13:30~14:30 (차선) | 오후 4~6시(마감대) · 연휴 전후 · 대형 이슈 터진 날 |

- campaign-report에 요일·시간대별 회신 분포가 쌓였으면 **내 데이터 우선**, 위 표는 기본값.
- 대형 속보(재난·정치 이슈)가 터진 날은 하루 미룬다 — 어차피 묻힌다.

## ④ 예약 실행 (자동 발송 없음 — 초안 + 캘린더 리마인더)

이 패키지에 자동 발송 도구는 없다. 예약은 **"초안 준비 + 발송 시점 알림"** 조합으로 구현한다.

1. 승인 게이트(press-distribution ④와 동일)를 통과하면 기자별 `mcp__Gmail__create_draft`
   (실명·이메일은 여기서만 주입) → `mcp__Gmail__label_thread`로 `언론홍보/캠페인/{캠페인명}` 부착.
2. `mcp__Google_Calendar__create_event` — 제목 `📮 팔로업 발송: {캠페인명} N통`,
   시작 = 권장 발송 시각, 알림 10분 전. 설명란에는 **기자 코드 목록만**(실명 금지).
3. 시각이 되면 사용자가 Gmail 임시보관함에서 초안을 확인 후 직접 발송.
4. 초안 수정이 필요하면 `mcp__Gmail__update_draft`로 갱신(재생성 말고 갱신).

## ⑤ 엠바고 관리

- 제목 맨 앞에 `[엠바고: MM/DD(요일) HH시까지]` + 본문 첫 줄에 동일 문구 반복.
- `mcp__Google_Calendar__create_event`로 해제 시각 이벤트(`🔓 엠바고 해제: {캠페인명}`) 등록.
- 해제 전 게재를 발견하면 감정 대응 금지 — 해당 기자에게 정중히 확인 요청 1회, 이후 엠바고
  대상에서 제외(다음 캠페인부터 해제 후 일반 배포만).
- 엠바고 브리핑은 관계 스코어 +3 이상 기자에게 우선 제안(신뢰 기반).

## ⑥ 정기 소식 (반복 발송 — 뉴스레터형)

- 대상: **옵트인 기자만** — 회신으로 관심을 표한 기자(①~⑤ 유형) 중 "다음 소식도 달라"는
  의사가 확인된 코드. 무응답 기자는 정기 소식 대상이 아니다.
- 상한: **월 1회**. 실릴 만한 뉴스가 없는 달은 건너뛴다(채우기용 소식 금지).
- 형식: 3~5줄 브리핑 + 자료 링크. 수신거부 문구 필수.

## 다른 스킬과의 연결
- 무응답 판정·회신율 데이터 → **campaign-report** · 팔로업에 대한 회신 → **reply-handler**
- 새 정보(2줄)가 없을 때 → **competitor-coverage**의 업계 이슈 연결 앵글 활용

## 절대 하지 말 것
- D+7 이전 팔로업 · 캠페인당 2회 초과 접촉 · 새 정보 없는 리마인더 · 수신거부 기자 접촉
- "자동으로 발송해두겠습니다" 류 안내(자동 발송 도구 없음 — 항상 사용자가 직접 발송)
- 엠바고 파기 기자에게 감정적 항의 · 무응답 기자를 정기 소식 명단에 편입
